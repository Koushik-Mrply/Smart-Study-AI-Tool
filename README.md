# Task 1: Build Your First AI Tool - Smart Study AI

An interactive, multi-feature educational web application powered by the Google Gemini 2.5 Flash LLM. This tool enables users to smoothly navigate between explaining complex concepts simply, summarizing dense paragraphs, and building self-assessment quizzes on the fly.

## Features
- **Explain a Concept:** Breaks down tough ideas using easy-to-understand analogies.
- **Summarize Text:** Condenses long passages into bite-sized, bulleted formats.
- **Generate Quiz Questions:** Instantly drafts interactive multiple-choice checkpoints.

## Completed Challenges
- **Graceful Empty Input Handling:** Prevents blank queries from triggering API errors.
- **Chat History Maintenance:** Persists conversations within active browser sessions.
- **Web Interface Design:** Styled custom HTML/CSS frameworks directly on top of Streamlit layout engines.
- **Markdown Rendering:** Supports clean bolding, bullet structures, and code-block formatting.
- **Loading Animation:** Utilizes dynamic user-facing spinners during processing phases.
